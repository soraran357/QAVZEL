01 / プロジェクト概要

必要な管理機能を、
ひとつに集約。

QAVZEL Coreは、Discordサーバーの管理・保護・運営を サポートする多機能Botです。 処罰や警告の管理から、ログの記録、認証、 チケット対応まで。サーバー管理に必要な機能をまとめています。

個人開発プロジェクト / 個人利用
02 / 主な機能

運営を支える、主な機能。

日常の管理作業をひとつずつ、
使いやすいコマンドとパネルに。

01
⚖

モデレーション

Kick・BAN・Timeout・警告などを一元管理。 処罰理由や履歴をケースとして記録し、 警告回数に応じた自動処罰も設定できます。

警告管理 処罰履歴 自動処罰
02
▤

ログ管理

メッセージの編集・削除、参加・退出、 ロール変更、VC移動などを記録。 検索やCSV出力にも対応。

イベントログ CSV出力
03
⌁

自動検知

招待リンク、連投、同じ内容の連投、 大量メンションを検知。 検知時の対応や対象外設定も調整できます。

スパム対策 詳細設定
04
◈

認証システム

画像認証またはWeb認証に対応。 認証完了後にロールを付与し、 メンバー管理をサポートします。

画像認証 Web認証
05
▣

チケット

問い合わせ窓口を作成。 プライベートチャンネル方式と フォーラム投稿方式から選べます。

非公開チャンネル フォーラム
06
☷

ルール・ロールパネル

ルール同意やロール選択をパネル化。 ボタン、ドロップダウン、チェックボックス、 リアクション式に対応。

ルールパネル ロールパネル
03 / カスタマイズ

サーバーに合わせて、
細かくカスタマイズ。

機能のON/OFFや動作、パネルの表示内容・ デザインなどをコマンドから設定できます。

A
設定を柔軟に変更 自動検知のしきい値や対応、ログ対象などを調整。
↗
B
パネルの見た目も編集 文章やボタンの色、表示先などを後から変更。
↗
C
状態をコマンドで確認 /botcheck で権限や設定の状態を診断。
↗
04 / コマンド

シンプルなスラッシュコマンド。

Discord上から必要な操作へ
すばやくアクセス。

QAVZEL CORE / コマンド表示例
/ botcheck 権限・設定の診断 準備完了
/ logsetup auto ログの送信先をセットアップ 設定
/ panel verify 認証パネルを作成 認証
/ rolepanel create ロールパネルを作成 ロール
/ warnrule add 警告回数に応じた処罰を設定 管理
