# QAVZELTeam Bot紹介サイト

## ファイル
- `index.html`：紹介ページ
- `style.css`：デザイン・スマートフォン対応
- `script.js`：モバイルメニュー
- `assets/`：QAVZELロゴ・バナー

## 確認方法
`index.html` をブラウザで開いてください。公開時はフォルダ内のファイルをWeb公開ディレクトリへ配置します。

## 公開前の設定
Bot招待URL・サポートサーバーURLはまだ共有されていないため、未設定です。実際のURLが決まったら `index.html` の導入案内に追加してください。

掲載機能は提供されたREADMEに基づいています。自動検知は初期状態でOFF、Web認証は公開URL等の設定が必要です。
